Acesso de administrador

Para gravar direto no site, informe o token do GitHub (é a "senha" de administrador — veja o passo a passo no LEIAME). Sem token, você pode fazer as alterações aqui e baixar os arquivos para enviar ao GitHub manualmente.

Título, revisão e vigência

Aparecem no topo da tabela, no Excel e no PDF. Ex.: "Tabela de Preço Nacional 2027" · "Rev. 02".

Reajuste por família

Digite o percentual de cada família (ex.: 5 para +5%; use negativo para reduzir). Confira a prévia e aplique. O reajuste altera a tabela oficial; as tabelas especiais acompanham, porque o desconto é calculado sobre ela.
